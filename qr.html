Printing it

  • Keep the pale margin. It is part of the code - scanners need that clear border, and it is already built into both downloads.
  • Do not go below the minimum width shown above, and give it a little more if it will be scanned in poor light.
  • Dark code on a light background. Inverted codes fail on many phones.
  • Use the SVG for anything printed. The PNG is fixed-resolution and will soften when enlarged.
  • Scan the final print with more than one phone before ordering a batch.
